# Правила работы в репозитории

Проект: приложение «Сохранённые поиски авто» (тестовое задание WestMotors).

Документы:

- [`README.md`](README.md) — запуск, возможности, решения, время и ИИ.
- [`docs/spec.md`](docs/spec.md) — нормативное поведение.
- [`docs/style.md`](docs/style.md) — код-стиль и структура.

Если код и спека расходятся, сначала обновляется спека, затем код.

## Стек

React 19 · TypeScript 7 (strict) · Vite 8 · Mantine 9 · react-router 7 (hash)
· vitest + Testing Library · oxlint.

Node.js 22.12+.

## Команды

```bash
npm run dev         # дев-сервер
npm run build       # typecheck + прод-сборка
npm test            # тесты
npm run lint        # oxlint
npm run typecheck   # tsc -b
npm run data        # перегенерировать данные и фото из API b.abw.by
npm run check:grid  # сетка 4 px и паритет скелетонов (нужен dev-сервер)
```

Перед коммитом: `npm run lint && npm run typecheck && npm test && npm run build`.
Для изменений карточки, панели, тулбара или скелетона — ещё `npm run check:grid`.

## Структура

- `src/lib/` — чистая логика без React: её и тестируем в первую очередь.
- `src/state/` — единственное место работы с `localStorage` и хуки к нему.
- `src/hooks/` — переиспользуемые хуки без доменной логики.
- `src/components/<раздел>/` — `layout`, `lots`, `filters`, `searches`, `ui`.
- `src/pages/` — только композиция компонентов и вызовы из `lib`/`state`.
- `scripts/` — сбор данных и проверка вёрстки, запускается вручную, в бандл не входит.

## Инварианты

1. `src/data/lots.json` и `public/photos/*` руками не правятся — только `npm run data`.
2. Mantine — единственный источник UI-компонентов, включая `Select` (нативных подмен нет).
   Tailwind и другие UI-киты не добавляем. Свой CSS — только `src/styles/global.css`
   (дизайн-слой) и `src/theme.ts` (дефолты компонентов). Новые `.css`-файлы и
   переписывание компонентов «с нуля» — нет.
3. Базовые лоты не кладём в `localStorage`: там только сохранённые поиски и
   добавленные лоты, с версией схемы в ключе (`autosearch.v1.*`).
4. «Новый лот» — это `appearedAt > lastSeenAt` и совпадение с фильтрами. Не по `id`.
5. Фильтры нормализуются `normalizeFilters` перед сохранением и записью в URL,
   иначе появляются дубликаты поисков и «полные» диапазоны годов.
6. У каждой сортировки есть тай-брейк — порядок должен быть детерминированным.
7. Никаких `any`, `@ts-ignore` и `eslint-disable`. Если обход неизбежен, он
   обсуждается на ревью и оформляется документом, а не комментарием в коде.
8. Новая логика в `src/lib/` приходит с тестом.
9. `base` для сборки вычисляется из `GITHUB_REPOSITORY`; ассеты подключаются через
   `assetUrl()`, а не абсолютными путями.
10. Любой ввод, который может меняться часто (слайдер, цена), не пишет в URL на каждое
    событие: локальный черновик + `onChangeEnd`/debounce. Цена — без маски во время
    набора, применение адаптивное (пауза 250 мс) и фиксация по blur/Enter.
11. Высоты контролов и кегли подписей — из дизайн-слоя: инпуты и кнопки 36 px (`size="sm"`),
    строка подписи 20 px, кегль 14 px / 500. Не задавай размеры «на глаз» в компонентах.
12. Скелетон обязан совпадать по высоте с реальным блоком: меняешь карточку или панель —
    обнови `src/components/ui/Skeletons.tsx` и проверь `npm run check:grid`.
13. Все размеры — на сетке 4 px: шапка/навигация 64, контролы 36, тулбар 52,
    карточка 296, панель 368, строки текста 20/16/24. Рамки карточек и панелей —
    `box-shadow`, не `border`: border добавляет 2 px и ломает паритет скелетонов.
14. Единицы — только px (внутри Mantine — rem). `em` в наших стилях и медиа-запросах нет.
    Ховеры — только внутри `@media (hover: hover) and (pointer: fine)`.
15. Включён React Compiler (`compiler: true`): не добавляй `memo`/`useCallback` «на всякий
    случай». Если нужен отклик на скролл — класс через ref, без состояния React:
    состояние в скролл-хуке = перерендер на каждый кадр.
16. `Card.Section` должен быть прямым потомком `Card` — Mantine клонирует его, чтобы
    включить бесшовные отступы. Обёртка компонентом ломает высоту карточки.
17. Комментариев в коде нет. Причины решений и компромиссы — в `docs/spec.md` и `README.md`.
18. Если фото лота не загрузилось, подставляется случайное фото из базовых лотов;
    заглушка «Фото недоступно» не используется.

## Что нельзя

- Пушить и деплоить без явного разрешения владельца репозитория.
- Менять версии зависимостей вручную в `package.json` (только `npm install`).
- Хранить в репозитории локальные артефакты: `.scratch/`, `.npm-cache/`,
  `.playwright-browsers/` (они в `.gitignore`).
- Добавлять TODO/FIXME и закомментированный код.

## Стиль коммитов

`feat:`, `fix:`, `test:`, `docs:`, `chore:` + короткое описание по-русски.
Один коммит — одна законченная мысль.
